Список аниме

Что смотрю, что хочу посмотреть и что понравилось. Данные хранятся в вашем браузере.

Импорт и экспорт

ВажноСписок хранится только в этом браузере. Если очистить данные сайта или открыть файл в другом браузере, на другом устройстве или по другому адресу, список будет пустым. Делайте экспорт после важных изменений.

Как сохранить список

  1. Нажмите «Скачать файл». На компьютер сохранится файл anime-list.json.
  2. Храните его в надёжном месте: в облаке, на флешке или отправьте себе на почту.
  3. Чтобы восстановить список, нажмите «Выбрать файл», затем «Заменить список».
  4. Если файл не скачивается, нажмите «Скопировать текст» и вставьте его в текстовый файл с расширением .json.

Что делают кнопки

Заменить списокПолностью заменяет текущий список данными из поля. Перед заменой попросит подтверждение.
Добавить к спискуДобавляет записи из поля к текущим. Аниме с одинаковым названием пропускаются.
Скачать файлСохраняет весь список в файл.
Скопировать текстКопирует данные из поля ниже, чтобы вставить их куда угодно.
Выбрать файлЗагружает данные из файла в поле ниже. Список при этом не меняется.
